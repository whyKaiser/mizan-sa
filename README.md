# منصة ميزان

محاسبتك.. تبدأ من فكرة. منصة ويب تعليمية عربية RTL لتخطيط مشروع، تحليل الربحية والتعادل، تجربة «ماذا لو؟»، ومحاكاة القيود والقوائم المالية.

## حالة الإصدار 2.0

التخطيط والمحاكي والحفظ المحلي والحسابات السحابية مفعّلة ومختبرة. التسجيل بإيميل وكلمة مرور دون رسالة تأكيد، بناءً على نطاق النسخة التعليمية. عزل الحسابات والحفظ بين جلستين مستقلتين وتعارض التحديث وتغيير كلمة المرور اختُبرت فعليًا. وضع الزائر مستقل ويحفظ على المتصفح فقط.

الرابط: https://alrajhylmy909-dev.github.io/mizan-sa/

لا توجد استعادة كلمة مرور بالبريد أو خدمة SMTP. تغيير كلمة المرور من الملف الشخصي يتطلب معرفة الحالية. البريد هنا معرّف حساب، وليس دليلًا على ملكيته؛ لا تستخدموا بيانات حساسة أو حسابات أشخاص آخرين.

## التشغيل

يتطلب أدوات تطوير Node.js 22.12+ أو إصدارًا أحدث متوافقًا مع Vite 8، وnpm.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

افتح الرابط الذي يظهر في الطرفية. لا تفتح `index.html` مباشرة من نظام الملفات.

## البنية

- `src/domain.js`: التحقق والحسابات والقيود والقوائم.
- `src/ui.js`: قوالب الواجهات والأيقونات والتقرير.
- `src/main.js`: الحالة والأحداث والتنقل والنماذج.
- `src/data.js`: التخزين المحلي والسحابي ورسائل الأخطاء.
- `src/auth.js`: التحقق من كلمة المرور وتغييرها بعد التحقق من الحالية.
- `src/config.js`: إعداد الاتصال العام؛ لا مفاتيح سرية.
- `src/styles.css`: الهوية والتجاوب والطباعة.
- `infrastructure/schema.sql`: جدول المشاريع وسياسات الملكية RLS.
- `tests/`: اختبارات الحسابات والحفظ.
- `delivery/`: دليل المذاكرة العربي ومولد PDF وسجل التحقق.

## حسابات التخطيط

الثابت شهريًا، والمتغير لكل وحدة. الإيراد = السعر × الوحدات؛ التكلفة = الثابت + المتغير للوحدة × الوحدات؛ الربح = الإيراد - التكلفة. التعادل = الثابت ÷ مساهمة الوحدة، مع تقريب الوحدات للأعلى. عندما لا يمكن التعادل تعرض حالة واضحة بدل صفر مضلل. رأس المال مستقل عن ربح التشغيل.

المحاكي مستقل عن التقديرات الشهرية، ويبدأ برأس المال كرصيد نقدي افتتاحي. يدعم تكلفة البضاعة مع البيع، وثمانية أنواع عمليات، ويمنع السداد فوق الرصيد والقيد غير المتوازن. تقرير التخطيط يميز التقديرات عن العمليات المسجلة.

## تفعيل الحسابات

راجع `infrastructure/README.md` للإعدادات المطبقة واختبارات التكامل. مشروع Supabase المخصص على الخطة المجانية، مع RLS وحظر وصول الزائر إلى جدول الحسابات. `src/config.js` يحوي عنوان المشروع ومفتاح `sb_publishable_...` العام فقط. لا تضع `service_role` أو كلمة مرور قاعدة البيانات في المصدر العام.

GitHub Pages في مستودع عام وSupabase Free دون ترقية مدفوعة. المجانية محدودة بحصص الخدمة، وقد يتوقف مشروع Supabase المجاني بعد أسبوع خمول. لا توجد نسخ احتياطية تلقائية ضمن هذه الخطة؛ لا تعتمدوا عليه لحفظ بيانات حقيقية وحيدة. عند بلوغ الحد لا توافقوا على ترقية مدفوعة تلقائيًا.

## نشر GitHub Pages

```sh
npm test
npm run build:pages
```

انشر فرع `main` من مجلد `/docs` في إعدادات Pages. هذا المجلد **ناتج بناء مولّد فقط**؛ يعاد إنشاؤه مع كل بناء. لا تحفظ فيه المصدر اليدوي أو وثائق لا تريد استبدالها. `base` مضبوط على `/mizan-sa/`. إذا تغير اسم المستودع، حدّثه ثم أعد البناء.
